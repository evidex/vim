# Vim Configuration

## Overview
Personal Vim configuration repository. Based originally on https://github.com/amix/vimrc

## Installation 

- Clone repo
    `git clone https://github.com/evidex/vim .vim`
- Link vimrc
    `ln -s .vim/vimrc ~/.vimrc`
- Install plugins 
    `:PlugInstall`
- Add any non-public or device specific configurations to `~/.dotfiles/config/vimrc.vim`
